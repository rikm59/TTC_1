## Site Visit & Information Gathering

Collect the following before quoting:

| Factor | Why It Matters |
|--------|---------------|
| **Property size & shape** | Square footage / metres drives material quantities; perimeter drives edging linear feet |
| **Slope / terrain** | Increases labour 15–30%; tight spaces or hills add time |
| **Existing features** | Note plant beds, trees, hardscape, irrigation, soil type, access |
| **Desired services** | Routine maintenance vs. installation vs. seasonal clean-up vs. hardscape |
| **Service frequency** | Weekly / bi-weekly / monthly / one-time; more frequent = better results, higher cost |
| **Material preferences** | Mulch type, sod variety, paver material, plant species — directly affects material cost |
| **Budget constraints** | Tailor scope; avoid scope-creep surprises |

## Cost-Plus Pricing Model

```
Item Total = (Labour Hours × Hourly Rate) + Material Cost + Equipment/Transport Fee
```

Then add overhead and profit:
```
Final Price = Item Total × (1 + Overhead %) × (1 + Profit Margin %)
```

### Step-by-Step

1. **Determine labour hours** — by property size, task, and complexity
   - Mowing ¼ acre: 0.5–1 hour
   - Flower bed installation: 4–8 hrs per 10 m²
   - Sod installation: 2–3 labour hrs per 100 m²
   - Add travel time and crew size factor

2. **Select labour rate** — loaded rate (wages + payroll taxes + benefits + equipment): **$50–$110/hr**

3. **Estimate material quantities** — measure → multiply by unit costs → add 5–10% waste

4. **Add equipment & transport** — dump fees, rentals (sod cutters, tillers, loaders), fuel. Flat mobilisation fee: $25–$100/visit

5. **Apply overhead & profit** — typical landscape contractor:
   - Overhead: 10–20%
   - Profit margin: 10–20%
   - Premium/commercial: up to 30%

6. **Contract discounts** — 5–10% off per-visit rate for seasonal or annual contracts

## Quoting App Integration Notes

### Recommended Measurement Fields per Sub-type

#### Lawn Mowing / Routine Maintenance
- `sqft` — Lawn area (sq ft)
- `visits` — Visits per month
- `shrubs` — Number of shrubs to trim
- `beds_sqft` — Bed area for clean-out (sq ft)
- `edges_lf` — Edging linear feet

#### Flower Bed Installation
- `sqft` — Bed area (sq ft)
- `demo_sqft` — Grass removal area (sq ft)
- `edging_lf` — Edging linear feet
- `plants` — Number of plants
- `mulch_yards` — Cubic yards of mulch

#### Sod Installation
- `sqft` — Lawn area (sq ft)
- `demo` — Demo/kill existing lawn (sq ft)
- `sod_type` — 1=Bahia, 2=St. Augustine, 3=Zoysia

#### Tree/Shrub Planting
- `trees` — Number of trees (by size category)
- `shrubs` — Number of shrubs
- `tree_size` — 1=sapling, 2=semi-mature, 3=large

#### Seasonal Clean-Up
- `sqft` — Property area
- `leaf_bags` — Estimated bag volume
- `beds` — Number of beds to clean

### Recommended Profit Margins
- **Routine maintenance**: 45–55%
- **Installation (beds, sod, planting)**: 50–60%
- **Hardscape construction**: 55–65%
- **Seasonal clean-up**: 45–55%
